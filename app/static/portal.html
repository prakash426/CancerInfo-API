Why developers use it

Built for products that have to be right

Health content without a source is a liability. CancerInfo API makes provenance part of the data model, not an afterthought.

Every fact is cited

Organization, exact document URL and title, verification date, attribution text and reuse conditions on every record.

Country-aware

Guidance differs between countries. Each record states its jurisdiction, and ?country= returns that country's records first, plus global ones.

License-checked

Content is published only after its source document clears a license review. Anything unreviewed stays private, so the API fails closed.

One consistent shape

Canonical cancers, aliases and codes, 37 standard categories, uniform pagination and a single error envelope.

Smart search

Abbreviations and aliases resolve automatically: CRC, bowel cancer and colon cancer all find colorectal cancer.

Citations that stay current

Store record IDs, then re-check up to 50 at once with /v1/facts to drop anything withdrawn.
